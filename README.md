# undergraduate_navier_stokes_least_squares

The two codes of the repository were developed working with undergraduate students at Francis Marion University.

## Serial Code
* The serial code utilizes the deal.II software library - https://dealii.org/
* The code also employs the UMFPACK direct solver
  * for further information about UMFPACK with deal.II see the ReadMe in Downloads at https://dealii.org/ 
* The code has been tested, compiled and run with deal.II version 9.3.3

## Parallel Code
* The parallel code utilizes the deal.iI software library - https:/dealii.org/
* The code also employs the Trilinos parallel direct solver
  * For further information about Trilinos with deal.II see the ReadMe in Downloads at https://dealii.org/
  * The website below may be of interest for compilation of deal.II on supercomputers
    * https://github.com/geodynamics/aspect/wiki/Compiling-and-Running-ASPECT-on-TACC-Stampede2
